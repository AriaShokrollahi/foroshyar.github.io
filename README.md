# فروش‌یار — داشبورد مدیریت فروشگاه

داشبورد مدیریتی فارسی (RTL) برای فروشگاه‌هایی که هم‌زمان فروش آنلاین و حضوری دارن. سفارش‌ها، محصولات، انبار، مشتری‌ها، پیام‌ها و گزارش‌های مالی در یک رابط یکپارچه، ریسپانسیو و مینیمال.

> این پروژه یک **نمونه‌ی فرانت‌اند** است: داده‌ها نمونه (mock) هستن و بک‌اند ندارد. ساختارش طوری طراحی شده که اتصال به API واقعی ساده باشه.

## امکانات

**صفحه‌ی ورود و ثبت‌نام**
- تب‌های ورود / ثبت‌نام با پنل برند (مخفی در صفحه‌های کوچک)
- نمایش/مخفی کردن رمز عبور و نشانگر قدرت رمز
- اعتبارسنجی پایه‌ی فرم و انتقال به داشبورد

**داشبورد** (۱۳ صفحه)

| صفحه | محتوا |
|---|---|
| نمای کلی | KPIها، نمودار فروش، فروش بر اساس دسته‌بندی، آخرین سفارش‌ها، پرفروش‌ها، موجودی کم |
| سفارشات | تب‌های وضعیت (با فیلتر واقعی)، جستجو، فیلتر، مرتب‌سازی، خروجی، عملیات گروهی |
| محصولات | جدول محصول با دسته‌بندی، قیمت، موجودی، فروش و وضعیت |
| انبار | KPIهای موجودی، افزایش/کاهش موجودی، حداقل موجودی |
| مشتریان | مجموع خرید، میانگین سفارش، آخرین سفارش، وضعیت مشتری |
| پیام‌ها | چت با لیست گفتگو، شمارنده‌ی خوانده‌نشده و پاسخ آزمایشی |
| تحلیل فروش | KPIهای رشد و مرجوعی، روند درآمد، مشتریان جدید/بازگشتی |
| بازاریابی | کدهای تخفیف، کمپین‌ها، سبدهای رهاشده |
| نظرات | تایید، پاسخ، گزارش و حذف |
| ارسال | مرسولات و کد رهگیری |
| مالی | درآمد، هزینه، مرجوعی، سود خالص و تراکنش‌ها |
| اعلانات | سوییچ روشن/خاموش برای انواع اعلان |
| تنظیمات | اطلاعات فروشگاه، کاربران و دسترسی‌ها |

**جزئیات رابط**
- منوی کشویی اعلان‌ها و پیام‌ها در هدر (هاور در دسکتاپ، کلیک در موبایل)
- مسیریابی با هش (`dashboard.html#orders`) — رفرش و دکمه‌ی برگشت کار می‌کنن
- آیکون‌های خطی ساده و یکدست
- فونت وزیرمتن، اعداد فارسی

## اجرای پروژه

نیازی به نصب یا build نیست.

```bash
# روش ۱: مستقیم index.html را در مرورگر باز کنید

# روش ۲: با یک سرور محلی
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

نقطه‌ی شروع `index.html` (صفحه‌ی ورود) است. دکمه‌ی ورود به `dashboard.html` می‌رود و «خروج» برمی‌گردد.

> فونت وزیرمتن و Chart.js از CDN لود می‌شن، پس برای دیدن فونت و نمودارها اینترنت لازم است.

## ساختار پوشه‌ها

```
foroshyar/
├── index.html          صفحه‌ی ورود / ثبت‌نام
├── dashboard.html      داشبورد
├── css/
│   ├── base.css          توکن‌های طراحی (رنگ، شعاع، سایه) و ریست
│   ├── layout.css        سایدبار، هدر و چیدمان اصلی
│   ├── components.css    کارت، جدول، دکمه، تب، فرم، منوی کشویی، نمودار
│   ├── chat.css          صفحه‌ی پیام‌ها
│   └── auth.css          صفحه‌ی ورود
└── js/
    ├── icons.js          همه‌ی آیکون‌ها در یک فایل
    ├── data.js           داده‌ی نمونه و تنظیمات منو
    ├── components.js     سازنده‌های HTML (کارت، جدول، KPI، تب ...)
    ├── pages.js          یک تابع برای هر صفحه
    ├── charts.js         نمودارها (Chart.js)
    ├── chat.js           منطق چت
    ├── topbar.js         منوهای کشویی و شمارنده‌ها
    ├── app.js            روتر، سایدبار، رویدادهای عمومی
    └── auth.js           منطق صفحه‌ی ورود
```

ترتیب لود اسکریپت‌ها در `dashboard.html` مهم است:
`icons → data → components → pages → charts → chat → topbar → app`

## ریسپانسیو بودن

نقطه‌های شکست (`max-width`) در بالای `css/base.css` مستند شده‌اند:

| عرض | تغییر |
|---|---|
| ۱۱۸۰px | شبکه‌ی ۴ ستونی به ۲ ستون؛ چیدمان‌های دو ستونه زیر هم می‌روند |
| ۹۸۰px | فاصله‌ها و کادر جستجو کوچک‌تر می‌شوند |
| ۸۶۰px | سایدبار به دراور کشویی با دکمه‌ی همبرگری تبدیل می‌شود؛ چت به‌صورت «لیست ↔ گفتگو» |
| ۶۸۰px | یک ستون، فاصله‌های فشرده‌تر، منوی کشویی تمام‌عرض |
| ۴۲۰px | دکمه‌ی ورود فقط آیکون؛ کوچک‌ترین فاصله‌ها |

نکات پیاده‌سازی:
- ستون‌های گرید با `minmax(0, …)` تعریف شده‌اند تا محتوا از صفحه بیرون نزند.
- جدول‌ها داخل `.table-wrap` اسکرول افقی دارند.
- نمودارها داخل `.chart-box` با ارتفاع مشخص و `maintainAspectRatio: false` هستند.

## سفارشی‌سازی

**تغییر رنگ و ظاهر:** متغیرهای `:root` در `css/base.css` (مثل `--brand-1` و `--accent`).

**افزودن یک صفحه‌ی جدید:**
1. در `js/data.js` یک آیتم به `NAV_ITEMS` و یک ردیف به `PAGE_TITLES` اضافه کنید.
2. در `js/pages.js` تابعی با همان شناسه اضافه کنید که HTML برمی‌گرداند:
   ```js
   Pages.reports = () => card("محتوای گزارش‌ها", { title: "گزارش‌ها" });
   ```
3. در صورت نیاز آیکون جدید را به `ICON_PATHS` در `js/icons.js` اضافه کنید.

**کامپوننت‌های آماده:** `card()`، `dataTable()`، `kpiCard()`، `pill()`، `tabs()`، `toolbar()`، `button()`.

## اتصال به بک‌اند

نقاطی که باید با API واقعی جایگزین شوند:

| کار | محل |
|---|---|
| داده‌ی سفارش، محصول، مشتری و ... | آرایه‌های `js/data.js` |
| ارسال پیام چت | `sendMessage()` در `js/chat.js` |
| ورود و ثبت‌نام | `handleSubmit()` در `js/auth.js` |
| داده‌ی نمودارها | `js/charts.js` |
